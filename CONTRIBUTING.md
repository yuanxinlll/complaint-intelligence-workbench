# Contributing

Use English for repository documentation, UI text, code comments, logs, issues and pull requests. Local teaching notes can remain outside the shared repository.

Create a branch, explain the behavior change and run the synthetic unit tests. Do not overwrite another collaborator's work. Keep data and model versions explicit. Do not access historical holdout labels for model selection, fit features on validation data, relabel from model predictions or silently change evaluation samples.

Never commit complaint text or identifiers, raw archives, model weights, local credentials, review worksheets or per-record predictions. Obtain explicit agreement before adding dependencies, downloads, external APIs, paid services or deployment. Human review is required for every suggestion, regardless of score.
